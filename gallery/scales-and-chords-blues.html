Scales, Chords, Blues.

HTML slideshow · Browser · 2026 · Kramer Gibson

How to watch

  • Use the arrows (or the arrow keys) to move slide to slide. Home and End jump to the first and last slide.
  • Walks from a major scale into its Mixolydian cousin, then shows how each scale degree stacks into the chords that run underneath a 12-bar blues.
  • Click any scale card or bass diagram to zoom in on it.
  • Each blues slide has piano chords and bass notes you can open for that key.
  • There is a notes box under each slide for jotting what worked. On this public copy it saves to your own browser only, not back to my file.

Why it is here

This is the Week 3 deck from class: the bridge from "here is a scale" to "here is why the blues sounds the way it does." Posting it here means you can walk back through it at your own pace, outside class time, in whatever key gave you trouble.

Tools used

  • Plain HTML, CSS, and JavaScript, no build step, one file
  • Scale and blues slides generated from data so every key gets the same layout
  • Per-slide notes with a localStorage fallback when there is no save server behind the page
